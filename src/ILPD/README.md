# Ionizable Lipids

This tool classifies ionizable lipid is into regions.

```bash
ipld.sh -l -S output.txt -F frags file.smi
```
The resulting file `frags.smi` contains isotopically labelled
input molecules and fragments derived from those.

The most critical of the entries in the fragment file is
the version of the parent molecule where isotopic labels have been applied
to each atom. This table provides the key to the isotope numbers.

| Isotope | Classification |
| ------- | -------------- |
| 0 | Unclassified |
| 1 | q |
| 2 | q |
| 3 | q |
| 4 | q |

| 6 | q |
